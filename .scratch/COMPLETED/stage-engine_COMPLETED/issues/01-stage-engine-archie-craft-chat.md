# 01 — Stage engine prototype: animated pixel-art scene for archie_craft_chat

**What to build:** A native Godot "stage" renderer that replaces an event's static VN card art with a live, low-res pixel-art scene when `data/stages/<event_id>.json` exists. Prototype content: Spitalfields Market set + Archie rig for `archie_craft_chat`.

- Native canvas ~180x240 (3:4 VN slot), integer pixel scale (floor of frame px / 180), viewport size adapts to the frame so pixels stay square; nearest filtering.
- Layers with parallax (far wall + walkers, market/floor, fore), ambient life (string-light flicker, walkers, stall vendor).
- Actor rig from layered parts (legs, torso, head group w/ eyes/brows/mouth overlays, two posed arms); behaviours: breathe, blink, chew, talk flaps (length from card text), head tilt.
- Per-card direction data: timed steps (`set`, `play`, `talk`, `drop`, `throw`, `camera`). Start state of card N = fold of cards < N (Rewind/resume safe; no game state touched).
- Card 4: Archie stops chewing, mouth hangs open, a bit of falafel falls to the floor and stays there.
- Card 12: last bite, crumple, no-look throw; camera pans to the bin; wrapper lands; Archie doesn't react.
- Reduced motion: no ambient motion, card steps snap to their end state.
- Assets generated by `tools/stage_art/` (reproducible; artist can replace PNGs 1:1 later).

**Blocked by:** None

**Relevant files:** `data/events/archie_craft_chat.json`, `systems/events.gd` (`is_vn_mode`, convention art), `scenes/screens/event.gd` (VN frame), `autoload/GameData.gd` (event dir loading), `systems/preferences.gd`, `assets/character-references/Archie/Archie_reference.png`, `CODEMAP.md`

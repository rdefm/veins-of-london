# 35 — Recording test double for map stop draw calls, closing ticket 27's centering gap

**What to build:** `map_canvas.gd`'s stop rendering (`_draw_vein_stop`/`_draw_faction_stop`/`_draw_unclaimed_stop`, and the shared helpers they call — `_draw_ring_stop`, `_draw_interchange_ring`, `_draw_ore_symbol`, `_draw_centered_text`, plus `Icons.draw_*`/`OreGlyphs.draw`) all draw via immediate-mode `CanvasItem.draw_circle`/`draw_arc`/`draw_rect`/`draw_colored_polygon`/`draw_line`/`draw_string` calls. These are only legal inside an active `_draw()` notification and return nothing queryable, so this project's headless test suite has never exercised them directly — see the "not exercised here" comments in `tests/test_icons.gd` and `tests/test_ore_glyphs.gd`, and `27-map-stop-glyphs-completeness_COMPLETED.md`'s own workaround: it added `MapCanvas._unclaimed_ring_style()` as a pure, testable proxy for the *style* an unclaimed stop's ring would use, but that proxy can't prove a glyph is actually drawn, or that it's centered — the literal thing ticket 27's own acceptance checklist asked for ("`map_canvas` tests updated/added asserting an ore glyph is drawn (and centered) for player, faction, and unclaimed stops alike") and couldn't fully deliver.

Build a lightweight recording test double that can stand in for the `target: CanvasItem` parameter these draw helpers already thread through, so a headless test can call `_draw_vein_stop(stop)` (or similar) against the fake and assert what was drawn — shape kind, position, colour — without a live renderer or viewport.

**Blocked by:** 34 (spike decides whether any production `target: CanvasItem` params need retyping, and if so, which — do not guess this here)

**Status:** ready-for-agent (34 resolved — see ticket 34's `## Answer`: shadowing fails, retype `target` on `_draw_ring_stop`/`_draw_interchange_ring`/`_draw_ore_symbol`/`_draw_centered_text` in `map_canvas.gd`, `draw_padlock`/`draw_pin` in `icons.gd`, and `draw`/`_draw_hourglass`/`_draw_bolt`/`_draw_star4`/`_draw_die5`/`_draw_asterisk8` in `ore_glyphs.gd`)
